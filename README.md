# PRODELINSA — sitio estático

Catálogo mayorista de PRODELINSA para comercios de El Salvador. Está hecho con HTML, CSS y JavaScript del navegador; no requiere Node.js, Vite, dependencias ni un proceso de compilación.

## Funciones

- Catálogo con filtros por categoría y búsqueda.
- Selector de cantidades por producto, detalle del producto y carrito.
- Carrito y datos del comercio guardados en el navegador entre visitas.
- Envío de la solicitud completa a WhatsApp (+503 7319 5993).
- Diseño adaptable a móviles y escritorio.

El sitio sirve como vitrina y canal de cotización. No procesa pagos: precios, existencias y entrega se confirman con ventas por WhatsApp.

## Archivos

- index.html: contenido y estructura.
- script.js: catálogo, carrito, formulario y enlaces a WhatsApp.
- styles.css: estilos del sitio.
- static.css: ajustes del sitio estático.
- Productos/: fotografías y logotipo.

## Publicar en Hostinger

Sube index.html, script.js, styles.css, static.css y la carpeta Productos/ al directorio raíz del sitio (public_html). No se necesita instalar paquetes ni ejecutar una compilación.

## Publicar con GitHub Pages

En el repositorio, abre Settings → Pages, elige Deploy from a branch, selecciona main y la carpeta / (root).
